# Widgets

Every shadcn/ui component lys-ui implements, as it paints, captured on a
real compositor with its overlay open. The page switches palette with
the site's theme toggle.

The shots come from the shadcn gallery (`just shadcn`) in its `-shots`
mode: `just docshots` runs it on a private headless sway at scale 2,
and the site's deploy workflow does the same on every push, so the
shots always show the current code.
